# Libras ao vivo
Reconhece o alfabeto manual de Libras pela câmera, mostra a letra na tela e fala em voz alta.
Inclui as letras com movimento (Ç, H, J, K, Z) e modo treino.

## Como testar no VS Code
1. Abra esta pasta no VS Code.
2. Instale a extensão **Live Server** (Ritwick Dey).
3. Botão direito em `index.html` > **Open with Live Server**.
4. Clique em "Ligar a câmera".

Se a câmera não abrir, teste `teste-camera.html` do mesmo jeito. Não abra o arquivo com duplo clique (file://).

## Letras com movimento
- J: mindinho para cima, desenhando um J
- K: dois dedos em V, subindo
- H: dois dedos girando
- Ç: mão em C balançando
- Z: indicador desenhando um Z
Faça o movimento de forma ampla e sem pressa, com a mão inteira visível.
